# 🛒 Sistema de Inventario y Ventas

> **Versión Completa 1.0** — Creado por Emanuel Doñé Martínez

Sistema profesional para gestionar inventario, clientes, ventas, facturas en PDF y reportes con gráficos.

---

## ✨ Características

- 🔐 **Registro e Inicio de Sesión** con contraseña protegida
- 📦 **Gestión de Productos**: Agregar, Ver, Buscar, Editar, Eliminar, Stock Bajo
- 👤 **Gestión de Clientes**: Agregar, Consultar, Buscar, Editar, Eliminar
- 🧾 **Ventas Inteligentes**: Descuento automático de stock al registrar venta
- 🖨️ **Facturas en PDF**: Genera facturas profesionales listas para enviar
- 📊 **Dashboard con Gráficos**: Ventas por mes, Productos más vendidos
- 💾 **Respaldos Automáticos**: Copia de seguridad al abrir y cerrar
- 📋 **Reportes**: Historial completo + Ventas del día
